# PDF pipeline v0.2.0

Primary sources: [PyMuPDF page API](https://pymupdf.readthedocs.io/en/latest/page.html), [Docling pipeline options](https://docling-project.github.io/docling/reference/pipeline_options/), [formula enrichment](https://docling-project.github.io/docling/usage/enrichments/), [figure export](https://github.com/docling-project/docling/blob/main/docs/examples/export_figures.py), [MinerU output](https://opendatalab.github.io/MinerU/reference/output_files/). No upstream code copied; verify installed version and license. PyMuPDF is AGPL/commercial. Docling models may require network download at first use; only run with authorized dependencies and local documents. Never send copyrighted/private inputs to hosted services without authorization.

1. Inventory edition, SHA-256, physical page (1-based) and printed label separately; use a fresh private output directory per bounded chunk. Native mode reads PyMuPDF text blocks, coordinates, bitmap occurrences, vector count and actual page renders. Native extraction is not OCR, reading-order inference or figure detection. Text presence does not exclude scanned/mixed regions. Rotated page render coordinates differ from unrotated text boxes; do not silently overlay.
2. Semantic mode converts the same page range with Docling table structure, OCR, formula enrichment, page and picture images enabled, and exports structured JSON, Markdown, figure/table PNGs and provenance. Raw document export is authoritative for the parser output, not for the book. Check manifest, returned page provenance and missing pages/objects; incompatible APIs or failed models must fail visibly. Do not downgrade to native and call that semantic success. Formula enrichment produces candidate LaTeX, not algebraic verification. Figure crops are candidate regions, not semantic interpretation.
3. Optional independent route: use installed MinerU according to its version-specific official docs, retain original structured output, page index, bbox convention, captions, formula and table structures. Normalize only after inspecting schema, page offsets, origin and scale. Use scripts/extraction_suite.py mineru for the bundled optional 4.x local adapter; normalize_mineru maps the structured content page_idx back to original physical pages. See extraction-suite.md. Avoid comparing cropped/subset indices without mapping back to original physical pages.
4. Match original evidence by page and region, verify figure/table captions and subpanels, table header/row associations, units, blanks versus zero, merged cells, continuation headers, equation signs, subscripts/superscripts, brackets, definitions. Distinguish raster images from vector drawings; crop/render original page rather than reconstructing schematics. Do not equate bitmap count to number of figures. For charts record axis type, units, calibration and reading uncertainty; pixel estimates are not explicit source values. Prefer explicit text/table data over graphic estimates for identical conditions, and flag contradictions for review.
5. Review log: source hash, page, region, parser/version, original candidates, discrepancy, verified literal or uncertainty, reviewer and status. Any unresolved sign, exponent, unit, material or critical dimension blocks dependent verified rules. Agreement between parsers is not evidence of correctness. Keep review separate from parsed status.
6. Keep source PDFs and complete extracts under ignored private-evidence/ or local-library/. No source redistribution without rights. Publish original rules, citations, and independently authored code only. A parser success does not prove a chapter learned.

Local native extraction and semantic adapter are executable; external backend installation and model integration are environment dependent. No actual textbook benchmark yet.
