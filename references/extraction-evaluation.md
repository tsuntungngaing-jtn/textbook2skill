# Evaluation of PDF extraction

Use [OmniDocBench](https://github.com/opendatalab/OmniDocBench) and its [evaluation Skill](https://github.com/opendatalab/OmniDocBench/blob/main/skills/SKILL.md) as the external benchmark for text, formula, table and reading order. Pin dataset and evaluator versions; evaluate the same pages, model/configuration, language and output format. Use official metrics (e.g. formula CDM and table TEDS/TEDS-S where applicable), not the local strict scorer as a substitute.

Local scorer: both JSON files have {"source_sha256":"64 hex digits","items":[{"id":"p2-value1","kind":"number","value":"-0.15 MPa"}]}. Kind must be text, number, unit, formula, table_cell, figure_label or reading_order. Stable IDs from independent annotations, physical page/region locators maintained in annotation record. Predicted item value is literal string; whitespace collapse only, no case or minus-sign stripping. Exact transcription precision, recall and F1 per kind and overall; missing, extra and mismatch IDs separately reported. Undefined denominators return null. Missing/abstained predictions count against recall. This tests literal transcription, not formula equivalence, chart digitization, region IoU or table semantics.

Pilot: freeze 30–50 unseen pages spanning native, scanned, multicolumn, mixed-language, dense equations, complex tables, vector figures and plotted data. Independently annotate critical numerical/unit/formula fields, cells, figure captions and reading order. Evaluate native-only vs semantic vs source-reviewed hybrid under identical page sets; report failures, runtime, counts, error categories and denominators. Critical fields admitted into executable rules must be source reviewed with zero unresolved critical discrepancies; do not claim 100% whole-book accuracy. Document chart reading uncertainty and independently evaluate geometry/caption association separately. No actual measured accuracy in v0.2.0 until pilot.

For frozen private holdout evaluation use extraction-suite.md and scripts/extraction_suite.py freeze/evaluate. This extends the strict scorer with stratum-level counts and critical-field errors; the official metrics still require separately installed upstream evaluators.
